# Standalone HUD preview

Open `index.html` directly in a browser. No installation, server, network, or game files are required.

Use the controls to fire, reload, change health, and simulate a receiver disconnect. All data is local sample data. The arena illustration substitutes for the native app's camera and weapon model. This preview does not access Bluetooth or the game backend.

Delete this entire `hud-preview` folder whenever you no longer need it. The actual game does not import anything from this folder.
